Setup Steps

1

Create a Twilio account

You already have Twilio set up for SMS. Same account works for WhatsApp.

2

Enable WhatsApp Sandbox (for testing)

In Twilio Console → Messaging → Try it out → Send a WhatsApp message.
Your test number is +14155238886. Customers text join <word> to opt in to sandbox.

3

Add to Render environment variables

Go to Render → your service → Environment → Add:
TWILIO_WHATSAPP_NUMBER = +14155238886 (sandbox) or your approved number

4

For production — apply for WhatsApp Business API

In Twilio Console → Messaging → Senders → WhatsApp senders → Apply.
Takes 1–5 business days. Then replace the sandbox number with your approved number.

5

Add WhatsApp numbers to customers

When adding/editing customers, enter their WhatsApp number. It can be the same as their phone number — WhatsApp uses regular phone numbers.
