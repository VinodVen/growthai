Role Overview

We are looking for a Performance Test Engineer to help us ensure Revvio can scale reliably as we grow from hundreds to thousands of businesses. You will design, build, and execute performance and load tests, identify bottlenecks, and work closely with the backend engineer to fix them.

This is a high-impact role — you will be the first dedicated QA/Performance hire and will set the testing culture for the engineering team.

Responsibilities

Performance & Load Testing

  • Design and execute load tests simulating concurrent multi-tenant usage across 100s of businesses
  • Test high-traffic endpoints: /api/do-checkin/<slug>, /cron/run-automations, /generate-social-post, /bulk-send
  • Simulate bulk SMS/email campaign delivery to 500–2000 customers per business
  • Measure response times, throughput, error rates, and database query latency under load
  • Test AI content generation endpoint stability under concurrent requests (OpenAI integration)
  • Identify and document database N+1 query issues, slow queries, missing indexes

API & Integration Testing

  • Write functional API tests for all 134 REST endpoints
  • Test Twilio webhook reliability, Stripe payment webhook signature validation, Square POS sync
  • Validate multi-tenant data isolation — ensure business A cannot see business B's data
  • Test authentication edge cases: session expiry, concurrent logins, invalid tokens
  • Test QR check-in flow end-to-end: join → coupon generation → SMS delivery → redemption

Database Performance

  • Analyze PostgreSQL query plans for slow queries using EXPLAIN ANALYZE
  • Test database connection pool behavior under peak load (SQLAlchemy pool_size=10)
  • Validate live migration safety — run migrations against staging database and verify data integrity
  • Stress test the customer journey automation engine with large audience enrollments

Monitoring & Reporting

  • Set up performance baselines and regression thresholds
  • Create performance dashboards and share results with the engineering team
  • Document findings with clear reproduction steps and recommended fixes
  • Work with Render.com metrics (CPU, memory, response time) during load tests
