1. App Overview

Revvio is a multi-tenant SaaS platform that helps local businesses grow their customer base through AI-driven marketing automation.

Core Capabilities

  • AI-generated marketing campaigns (Email, SMS, WhatsApp)
  • Automated customer journeys with multi-step triggers
  • QR code check-in with welcome coupons & analytics
  • Public business landing page with product catalog
  • AI-powered social media post generation & publishing
  • Revenue ROI tracking & Square POS integration
  • White-label branding per client (Enterprise plan)
  • Admin panel for managing all client accounts
All customer data, campaigns, and settings are scoped by business_id. No data leaks between tenants.

5. Feature Modules

5.1 Customer Management

  • Add customers manually or via CSV / paste import
  • Fields: first name, last name, email, phone, DOB, WhatsApp, source
  • Segments: all, new, loyal, inactive, birthday, SMS-only, WhatsApp
  • Duplicate detection and merge
  • Unsubscribe / suppression list management
  • Individual customer profile with full campaign history

5.2 Campaigns

  • Create email, SMS, or WhatsApp messages
  • AI-generated message content via OpenAI (gpt-4o-mini)
  • Schedule or send immediately to a segment
  • Open tracking (email pixel), link click tracking
  • Campaign cloning, editing, deleting

5.3 AI Automations

Toggle-based automations that run every 30 minutes via cron:

AutomationTriggerAction
Welcome MessageNew customer joinsInstant SMS/WhatsApp
Weekly SpecialEvery TuesdayAI writes & sends offer
Flash DealSlow daysAI sends flash discount
Birthday OfferCustomer's birthdayPersonalized SMS
Win-BackNo visit in 30 daysRe-engagement SMS
Google Review Request3 days after signupReview link SMS
Loyalty MilestonesVisit count thresholdReward message
Cron endpoint: GET /cron/run-automations?secret=CRON_SECRET
Triggered externally (cron-job.org) every 30 minutes.

5.4 Customer Journeys

  • Visual multi-step automation builder
  • Triggers: signup / birthday / win-back / manual
  • Steps: wait X days → send email/SMS → check open → branch
  • Per-journey analytics (sent, opened, clicked)
  • Audience enrollment and preview

5.5 AI Social Posts

  • Describe a promotion → AI writes Instagram, Facebook, WhatsApp, Story posts
  • Ready-made templates (no AI needed)
  • Post directly to connected Facebook/Instagram pages
  • Visual post queue with reordering

5.6 Visual Post Designer

  • 8 CSS-based design templates
  • Fill in headline, subtext, badge, business name, address
  • Download as PNG (html2canvas)
  • Post directly to Facebook/Instagram via Meta Graph API

5.7 Public Landing Page /p/<slug>

  • Dark gradient hero with business logo, name, address
  • Product/service catalog with photos and category filter
  • Featured products section
  • Join VIP list form: first name, last name, phone, email, DOB
  • Welcome coupon card shown after joining (if enabled)

5.8 QR Check-In

  • QR code generated via api.qrserver.com pointing to /p/<slug>
  • Print-ready QR page
  • Stats: today / week / all-time check-ins
  • Blast SMS: send public page link to all existing customers
  • Coupon analytics: issued, redeemed, pending, redemption rate

5.9 Welcome Coupon System

  • Business configures in /branding: amount (e.g. $5 / ₹100), description, expiry days
  • Customer joins → unique 10-character alphanumeric code generated
  • Digital coupon card shown with QR code and expiry date
  • SMS sent to customer with coupon code
  • Staff scans coupon QR → /redeem/<code> → verify and mark as redeemed
  • Full analytics on QR dashboard page

5.10 Revenue ROI

  • Log revenue manually per campaign
  • Total revenue tracked, average per visit calculated
  • Campaign-level ROI breakdown

5.11 Square POS Integration

  • OAuth2 connect flow at /square-connect
  • Auto-logs revenue when payment.created webhook fires
  • Manual sync of historical payments
  • Matches payments to customers by email/phone

5.12 Branding & Permissions

  • Upload logo, set brand name (replaces "Revvio" in header)
  • Pick brand color (hex picker)
  • Custom subdomain field (requires DNS setup)
  • Feature toggles — hide/show any feature per client
  • Configure welcome offer coupon

5.13 AI Business Assistant

  • Full-page chat interface at /ai-agent
  • Context-aware: knows customer count, campaigns, plan
  • Floating widget on dashboard (bottom-right corner)
  • Guides businesses through setup step by step

5.14 Onboarding Checklist

  • 6-step checklist shown to new users on dashboard
  • Progress bar with completion percentage
  • Steps: profile → customers → campaign → branding → QR → ROI
  • Dismissable via "Dismiss" button

7. User Flows

New Business Registration

/register → fill form → /onboarding wizard (business type, tone, peak days, automations) → /dashboard with onboarding checklist

Customer Joins via QR Code

Customer scans QR code
→ /p/<slug> (sees products catalog)
→ Fills name / phone / email / DOB
→ POST /api/do-checkin/<slug>
→ Customer created in DB, welcome SMS sent
→ Coupon card displayed (if welcome offer enabled)
→ SMS with coupon code sent to customer

Staff Redeems a Coupon

Customer shows coupon QR code
→ Staff scans with phone → /redeem/<code>
→ Sees: customer name, join date, offer details
→ Clicks "Mark as Redeemed"
→ POST /api/redeem-coupon/<code>
→ Marked used in DB, analytics updated

Send AI Campaign

/create-campaign → select type + channel
→ POST /generate-message (AI writes content)
→ Review & edit message
→ POST /send-campaign/<id> or /send-sms/<id>
→ Sent via Resend (email) or Twilio (SMS)
→ Opens and clicks tracked

Generate & Post Social Content

/social-posts → describe promotion in textarea
→ POST /generate-social-post (OpenAI, ~10s)
→ Shows Instagram, Facebook, WhatsApp, Story content
→ Click "Post to Facebook" → POST /api/post-to-social
→ Published via Meta Graph API v18.0

9. Third-Party Integrations

OpenAI (gpt-4o-mini)

  • Used for: campaign messages, social posts, AI assistant chat
  • Called via: requests.post (not openai SDK — avoids httpx conflicts)
  • Timeout: 20 seconds | max_tokens: 350
  • Helper function: _call_openai(prompt, max_tokens, timeout)

Twilio

  • Used for: SMS delivery, WhatsApp messages
  • Env vars: TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_FROM_NUMBER
  • Inbound SMS handled at: POST /twilio/webhook

Resend

  • Used for: Email delivery (transactional + marketing)
  • From address configured via RESEND_FROM_EMAIL env var
  • Supports custom domain email per client

Stripe

  • Used for: Pro / Enterprise subscriptions
  • Plans: Starter ($19/mo), Pro ($50/mo)
  • Webhooks: payment confirmation, subscription lifecycle events

Meta Graph API v18.0

  • Used for: Post to Facebook Pages and Instagram Business accounts
  • OAuth flow: /social-connect → /facebook/callback
  • Stores long-lived page access token per business in DB

Square

  • Used for: Auto-log revenue from POS payments
  • OAuth2 flow: /square-connect → /square/callback
  • Webhook receiver: POST /api/square-webhook (payment.created events)

Google OAuth2

  • Used for: "Sign in with Google" on registration and login pages
  • Endpoint: POST /auth/google

10. Deployment

Platform: Render.com

# Procfile
web: gunicorn main:app --bind 0.0.0.0:$PORT --workers 1 --timeout 120 --preload
⚠️ Single worker required — background job state uses in-memory storage. Using multiple workers would lose job state between requests.

Important Deployment Notes

  • 1 worker only — required for in-memory state consistency
  • Timeout 120s — allows longer AI operations
  • Render load balancer has its own 30s HTTP timeout on free tier
  • Auto-deploy on push to main branch via GitHub

Database Migrations

Run automatically at startup in _do_migrations() (background thread, 2s delay). Uses ALTER TABLE IF NOT EXISTS — safe to run on every deploy.

Static File Storage

DirectoryContents
/static/logos/Uploaded business logos
/static/product-images/Product photos
/static/post-images/Generated social post images
⚠️ Ephemeral filesystem warning — Static file uploads are lost on Render redeploy. For production stability, migrate to AWS S3 or Cloudflare R2.

11. Admin Panel

Access

URL: /admin/login
Credentials: ADMIN_EMAIL + ADMIN_PASSWORD environment variables

Admin Capabilities

  • View all businesses: customer counts, campaign counts, plan, last login
  • Change any business's plan (free → pro → enterprise)
  • Login as any business for support (impersonation)
  • Add new business accounts manually
  • Delete business accounts and all associated data
  • Send messages to businesses
  • Manage campaign types (add / edit / delete categories)
  • View MRR summary and trial expiry alerts
